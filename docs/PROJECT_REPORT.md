# 期中專題報告：童軍倉庫智慧櫃位引導與借還終端機

---

## 摘要 (Abstract)
本專案針對童軍團器材庫房「物品品項龐雜、櫃位尋找費時、借還登記容易遺漏、帳物庫存不一致」等痛點，設計並實作了一套具備**「線下實體終端 ＋ 線上雲端管家」雙軌架構**的智慧倉儲管理系統。
線下實體端基於 **ESP32 微控制器與 MicroPython**，整合 **4×4 矩陣薄膜鍵盤**、**I2C OLED 螢幕**、**NeoPixel 貨架引導燈 (Pick-to-Light)**、**蜂鳴器聽覺反饋** 與 **伺服馬達電子櫃門鎖**，提供直覺的櫃位快速檢索、借出/歸還防呆計數與實體光導引；線上雲端端則整合 **LINE Bot、Google 試算表與 Google Gemini AI**，支援小隊員在營地或遠端透過自然語言查庫存、登記借還與諮詢露營技能，達成無人化高效庫存管理。

---

## 壹、 做什麼 (What)

本專案研發了一座 **「童軍倉庫智慧櫃位引導與借還終端機 (Scout Smart Locker System)」**。其核心任務為：
1. **櫃位快速檢索與光引導 (Pick-to-Light)**：
   支援使用者輸入童軍標準編碼（例如 `A1-2`、`B3-4`），毫秒級檢索器材品名與庫存。依據櫃位分區（A 區五金、B 區炊事、C 區食器、D 區工藝），即時點亮對應 RGB LED 燈條，在昏暗庫房中循光取物。
2. **實體門禁與借還自動計數**：
   終端機支援「借出 (Borrow)」、「歸還 (Return)」、「查詢 (Query)」三大模式。若庫存為 0 則發出聲光警報防呆；庫存充足時，伺服馬達旋轉 90 度開啟櫃門，3 秒後自動復位上鎖。
3. **手機端 LINE 智慧管家雙軌連動**：
   小隊員可直接在手機 LINE 輸入「查 虎頭鉗」、「借 虎頭鉗」或點選底部快捷鍵，後端自動更新 Google 試算表可用數與借出數，並記錄時間戳記與借用人員。
4. **AI 童軍技能顧問**：
   整合 Google Gemini 模型，隊員可在 LINE 隨時諮詢童軍工程架設、炊事用具搭配與安全規範。

## 貳、 給誰用 (Who)

1. **童軍團小隊長與小隊員**：
   在團集會、露營前夕，需要快速領取整組器材（如卡式爐、營釘、童軍繩），避免在混亂庫房中翻箱倒櫃，且在戶外營地能隨時用 LINE 確認裝備狀況。
2. **童軍團器材長 / 裝備管理員**：
   無需隨時駐守庫房盯梢，透過實體終端與 LINE Bot 的防呆機制，借出即扣帳、缺貨即示警，大幅減少盤點失誤與器材遺失。
3. **學校社團、創客空間與共享工具室**：
   系統結構具通用性，適用於各類社團道具庫房、實驗室耗材室與校園公物保管。

## 參、 怎麼做 (How)

### 3.1 系統架構與資訊流
系統採用「雙軌並行、軟硬虛實整合」的閉環架構：

```text
[使用者] 
   ├── 現場取物 ➔ [ESP32 實體終端 (4x4鍵盤 / OLED / 燈條 / 電子鎖)] ➔ [本機微型狀態機]
   └── 遠端操作 ➔ [手機 LINE Bot] ➔ [Google Apps Script 雲端後端] ➔ [Google 試算表資料庫 + Gemini AI]
```

1. **實體硬體端 (ESP32 + MicroPython)**：
   - **輸入層**：採用 **4×4 矩陣薄膜按鍵（未教過零件）**。由韌體透過動態行列掃描（Row 輸出 LOW、Col 內部上拉讀取）偵測按鍵按壓與防彈跳。
   - **判斷層**：MicroPython 內建狀態機與童軍庫存字典，處理代碼格式校正（`A12` ➔ `A1-2`）、模式切換與庫存增減。
   - **輸出層**：OLED 顯示即時品名與數量；NeoPixel 點亮分區引導燈；蜂鳴器發出提示音與警報；伺服馬達（50Hz PWM）精準控制開鎖與上鎖。
2. **雲端物聯網端 (GAS + Google Sheets + LINE Bot)**：
   - 以 Google Apps Script 撰寫微服務，處理 LINE Webhook 請求。
   - 包含智慧表頭動態適應演算法，自動搜尋「器材名稱」、「建檔總數量」與「現存可用數」欄位。
   - 執行 `SpreadsheetApp.flush()` 確保數據即時持久化寫入，並於「借還紀錄」自動追加時間戳記與登記人員。

## 伍、 下一步 (Next Steps)

1. **實體終端連網模組常駐化**：
   將 ESP32 實體終端開啟 WiFi Webhook 連線，將現場按鍵借還即時推播至 LINE 群組，實現跨場域即時廣播。
2. **RFID / 條碼掃描整合**：
   加入 RC522 RFID 感應模組，支援團員刷社員證借物、器材掃描標籤歸還，進一步提升借還效率。
3. **外殼機構 3D 列印實體化**：
   設計專屬壓克力或 3D 列印終端外殼，安裝於童軍團部鐵櫃門口，將原型驗證落地為日常實用裝置。
