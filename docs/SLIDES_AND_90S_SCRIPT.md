- **系統定位**：
  專為童軍團裝備庫房設計的智慧化借還與尋架引導終端機，解決昏暗庫房中「找不到、借不齊、帳不合」的三大痛點。
- **目標客群 (給誰用)**：
  1. **童軍小隊長/隊員**：露營前夕快速檢索器材位置，循光取物。
  2. **團部器材長/庫存管理員**：無人化借還計數、即時防呆防遺失。
  3. **校園社團器材庫**：可通用於各類道具室與實驗室。
- **核心特色**：
  - **Pick-to-Light 智慧尋架**：輸入櫃位自動亮起對應 RGB 燈號。
  - **閉環循環狀態機**：借出、歸還、查詢三種模式可無限次反覆操作。

### 【Slide 3：② 用了哪個沒教過的零件、它怎麼接？】
- **沒教過的零件**：**4×4 矩陣薄膜按鍵 (Membrane Keypad)**
- **零件原理簡述**：
  由 4 條 Row（行）與 4 條 Col（列）組成交織矩陣，僅需 8 隻 GPIO 即可監聽 16 個按鍵（包含 A、B、C、D、0~9、*、#）。
- **接線方式 (接線圖截圖處)**：
  - `Row 1 ~ Row 4` ➔ 連接 ESP32 的 **`GPIO 19, 18, 5, 17`** (設定為輸出 Pin.OUT)
  - `Col 1 ~ Col 4` ➔ 連接 ESP32 的 **`GPIO 16, 4, 0, 2`** (設定為輸入 Pin.IN + 內部上拉 PULL_UP)
- *(註：此頁請放上 Wokwi 接線全景截圖，重點框出 Keypad 與 ESP32 的 8 條彩線)*

### 【Slide 4：③ 程式怎麼判斷？(流程與關鍵程式碼)】
- **判斷流程圖**：

  - 借出：若庫存 > 0 ➔ 扣除 1、亮綠燈、開鎖 3 秒；若庫存 = 0 ➔ 警報拒絕。

- **關鍵程式碼片段**：
```python
# 1. 矩陣鍵盤動態掃描 (未教過零件核心)
def scan(self):
    for r_idx, r_pin in enumerate(self.row_pins):
        r_pin.value(0) # 輪流將 Row 拉為低電位
        for c_idx, c_pin in enumerate(self.col_pins):
            if c_pin.value() == 0: # 偵測到按下
                while c_pin.value() == 0: time.sleep_ms(10) # 防彈跳
                r_pin.value(1)
                return self.keys[r_idx][c_idx]
        r_pin.value(1)
    return None

# 2. 借出判斷與硬體聯動
```

### 【Slide 6：⑤ 卡過什麼、怎麼解的？】
1. **卡關點 1：Keypad 掃描時出現連點與幽靈字元 (Bounce Issue)**
   - **問題**：手指輕按一下數字鍵，螢幕卻連續輸入了兩三個相同字元。
   - **解法**：在偵測到低電位時，加入 `while c_pin.value() == 0: time.sleep_ms(10)`，等待實體按鍵完全釋放才回傳鍵值，完成軟體去彈跳（Debounce）。
2. **卡關點 2：ESP32 接腳衝突導致無法開機或讀值飄移**
   - **問題**：初始選用某些 GPIO 造成 ESP32 啟動時失敗。
   - **解法**：避開 Strapping Pins，將 Keypad Col 設在標準 GPIO 並開啟軟體上拉電阻 `Pin.PULL_UP`，確保未按壓時維持穩定高電位。
3. **卡關點 3：伺服馬達 PWM 頻率與 Duty 轉換不順**
   - **問題**：MicroPython 的 PWM Duty 範圍為 0~1023，直覺設 0~180 導致馬達狂抖。
   - **解法**：查閱 SG90 規格書（50Hz 週期 20ms，脈寬 0.5ms~2.5ms），換算出對應 Duty 值為 26 至 125，精確鎖定 0 度與 90 度。

# Part 3. 口試問答防守寶典 (老師可能問的問題與滿分回答)

### Q1：這一行 `r_pin.value(0)` 和 `Pin.PULL_UP` 是什麼意思？為什麼這樣寫？
- **滿分回答**：
  「老師，這就是 **4×4 矩陣鍵盤動態掃描** 的核心原理。因為 16 個按鍵不能每個都佔一隻腳，所以排成 4 行 4 列。我們平時將 Col（列）設定為內部上拉電阻（預設是 1，高電位）。當我要檢查第 1 行時，我就把第 1 行的 Row 接腳輸出 0（低電位）。如果這時候有人按下了這行的某個鍵，電路導通，對應的 Col 就會被拉低成 0！這樣我就能精確算出是第幾行第幾列被按下。」

---

### Q2：如果不用 4x4 Keypad，換成超音波感測器 (HC-SR04) 要改哪裡？
- **滿分回答**：
  「程式只需要改輸入端。原本是呼叫 `keypad.scan()` 取得鍵值，若換成超音波，我們會透過 GPIO 發送 10 微秒 Trigger 脈衝，計算 Echo 腳位高電位維持時間算出公分距離。在邏輯判斷上，改為：『當有人靠近小於 20 公分時，自動觸發喚醒引導燈』，而後續的 OLED 顯示、燈條指引與電子鎖判斷邏輯完全可以保持共用！」

---

### Q3：伺服馬達的 `duty` 為什麼算出來是 26 到 125？
- **滿分回答**：
  「因為標準伺服馬達頻率是 50Hz，一個週期是 20 毫秒（20ms）。MicroPython ESP32 的 10-bit PWM duty 範圍是 0 到 1023。0 度對應的脈衝是 0.5ms（0.5 / 20 * 1024 ≈ 26），90 度是 1.5ms（1.5 / 20 * 1024 ≈ 77），180 度是 2.5ms（2.5 / 20 * 1024 ≈ 128）。程式用公式 `26 + (angle / 180) * (125 - 26)` 就能線性對應出準確角度。」

---

### Q4：這個系統怎麼重複操作？會不會執行一次就結束了？
- **滿分回答**：
  「不會的，整個 `main()` 運行在一個非阻塞的 `while True:` 狀態機循環中。每一次完成借出或歸還後，伺服馬達開門 3 秒，隨後自動回歸 0 度鎖閉，NeoPixel 熄滅，OLED 自動刷新回 `update_idle_screen()` 待機首頁，隨時準備接受下一位小隊員輸入，完全支援不中斷重複借還。」
