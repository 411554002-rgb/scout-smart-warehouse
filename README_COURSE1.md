# 童軍庫房 LINE Bot 雲端智慧管家系統

> **創意應用 / 創意實作 期中專題**  
> 一個基於 **LINE Messaging API ＋ Google Apps Script (GAS) ＋ Google 試算表 ＋ Gemini AI** 的無人化器材管理方案。

---

## 📌 專題特色
1. **手機自然語言查庫存**：直接傳送「查 虎頭鉗」、「查 A1-2」即時回覆可用數與位置。
2. **實體借還自動扣帳**：傳送「借 虎頭鉗」、「還 虎頭鉗」自動連動 Google 試算表，可用數即時增減。
3. **庫存防呆機制**：可用數為 0 時阻擋超借；庫存滿額時提醒無須歸還。
4. **全庫房與分區清單**：支援「所有器材」統計看板，以及「A區」、「B區」快速分類列出。
5. **Quick Reply 快捷氣泡**：底部提供快捷按鈕，無須打字即可一鍵點選。
6. **Gemini AI 童軍大腦**：即時解答露營裝備配置與工程技能。
